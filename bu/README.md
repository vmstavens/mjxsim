
# Agents

This module contains the agents available. In the cable below, RL means the algorithm is purely reinforcement learning, IL means the method is purely immitation learning and RL+IL means it is a combination of both. 

| Agent                                      | Method Type      | Path                      | Paper      |
| -------------                              | ------------- | -------------             | ------------- |
| Vanilla Behavior Cloning                   | IL            | [agents/bc.py](./bc.py)   | Cell 2, Row 1 |
| Deep Reinforcement Learning with Reference | RL+IL         | [agents/drlr.py](./drlr.py)           | Cell 1, Row 2 |
| Diffusion Policy State Based | IL         | [agents/dps.py](./dps.py)                  | Cell 1, Row 2 |
| Diffusion Policy Vision Based | IL         | [agents/dpv.py](./dpv.py)                 | Cell 1, Row 2 |
| Proximal Policy Optimization | RL         | [agents/ppo.py](./ppo.py)                  | Cell 1, Row 2 |
